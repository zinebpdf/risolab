# risolab
risolab est un site web destiné à la risographie. Il contient :
- un outil pour utiliser les différentes couleurs présente à l'école supérieure d'Art & de Communication de Cambrai et tester plusieurs types de trames (ligne, carré, cercle, ellipse et croix). Il est également possible d'exporter les images pour les imprimer (en risographie).
- un nuancier de couleurs avec toutes les combinaisons bichromiques et trichromiques possibles, toujours avec les couleurs disponibles à l'école d'Art de Cambrai (celui-ci n'a pas encore commencé).
- des expérimentations, tests.

le site web est en cours de construction mais le code source est accessible pour que celles et ceux qui souhaitent y apporter leur patte puisse le faire librement, le réadapter en fonction des couleurs que vous avez dans votre école, studio, atelier, etc.
